Politique de confidentialité

Dernière mise à jour : 13 août 2026 · RGPD (UE/BE)

Responsable du traitement

Vincent Chauvaux — contact via le formulaire Contact sur hakou.be.

Données traitées

  • Formulaire Contact : nom, e-mail, message ; adresse IP et User-Agent côté serveur (anti-spam, sécurité). Stockage : fichier sécurisé sur VPS OVH (UE) ; envoi optionnel par e-mail (SMTP). Conservation : 12 mois maximum, puis suppression automatique.
  • Chat Stream : messages publics, pseudo (modifiable ; défaut dérivé d’un hash de l’IP), présence. Traitement en mémoire sur le VPS (historique court). Pas d’archivage longue durée.
  • Auth studio (comptes autorisés uniquement) : e-mail / nom Google, cookie de session HttpOnly. Accès restreint à une allowlist configurée côté serveur.
  • Enregistrements studio : si l’éditeur active l’option, le flux (image + son) est stocké sur le VPS OVH (UE), accessible uniquement via le studio (allowlist). Conservation : 60 jours (paramétrable), puis suppression automatique.
  • Stockage navigateur : préférence d’intro (sessionStorage), pseudo chat et choix cookies (localStorage).
  • Médias tiers (si consentement) : YouTube, SoundCloud, Instagram / Meta peuvent déposer leurs propres cookies et collecter des données selon leurs politiques.

Finalités et bases légales

  • Répondre aux messages (intérêt légitime / mesures précontractuelles).
  • Modérer le spam et sécuriser les API (intérêt légitime).
  • Animer le chat public radio (intérêt légitime ; messages volontaires).
  • Authentifier les éditeurs studio (exécution du service).
  • Conserver les lives enregistrés (intérêt légitime / exécution du service).
  • Médias / trackers tiers : consentement (ePrivacy).

Destinataires / sous-traitants

OVH (hébergement UE), GitHub Pages (hébergement site, États-Unis), Google (OAuth studio ; YouTube si embeds activés), Meta / SoundCloud si embeds activés, CDN jsDelivr (bibliothèques), proxy CORS éventuel (allorigins) pour synchroniser des flux publics.

Transferts hors UE

L’hébergement GitHub Pages et les services Google / Meta / SoundCloud peuvent impliquer des transferts vers les États-Unis. Les embeds tiers ne sont chargés qu’après acceptation via le bandeau cookies.

Vos droits

Accès, rectification, effacement, limitation, opposition, portabilité (lorsque applicable). Demande via le formulaire Contact en précisant l’objet « Données personnelles ». Vous pouvez aussi introduire une réclamation auprès de l’autorité de contrôle (en Belgique : APD / Gegevensbeschermingsautoriteit).

Pas de vente de données

Hakou ne monétise pas les données personnelles et n’utilise pas d’analytics publicitaire première partie.
